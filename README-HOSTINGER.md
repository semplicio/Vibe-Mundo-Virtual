# Instalação inicial na Hostinger

1. Faça um backup da instalação atual.
2. Abra `public_html` no Gerenciador de Arquivos.
3. Envie `Vybe-BS-Hostinger-1.0.0.zip` e extraia diretamente nessa pasta.
4. Confirme a substituição dos arquivos quando solicitado.
5. Não apague `config/database.php` nem a pasta `uploads` existentes.
6. Entre no painel administrativo e abra **Atualizações**.

O pacote não contém credenciais do banco, arquivos enviados por usuários nem
arquivos temporários. As próximas versões serão baixadas do repositório
`semplicio/e-commerce`, validadas por SHA-256 e instaladas pelo próprio painel.
